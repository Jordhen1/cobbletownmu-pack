# CobbleTownMU modpack (auto-updating)

This repo is the player modpack for the CobbleTownMU Cobblemon server. Launchers read it on every start and download whatever changed, so players never re-install the pack by hand.

## Players: Prism Launcher (recommended)

1. Download **CobbleTownMU-Prism.zip** from the pinned message in the server's Discord.
2. In Prism: **Add Instance > Import > choose the zip**.
3. Press **Launch**. The first start downloads all the mods (a few minutes); later starts only fetch updates.

Already have the pack in Prism? Add auto-updating to it instead:
1. Put [packwiz-installer-bootstrap.jar](https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest/download/packwiz-installer-bootstrap.jar) in the instance's `minecraft` folder (right-click the instance > Folder).
2. Edit Instance > Settings > Custom commands > tick it, and set **Pre-launch command** to:
   ```
   "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/Jordhen1/cobbletownmu-pack/main/pack.toml
   ```
